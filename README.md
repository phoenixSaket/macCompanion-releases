# Mac Companion releases

Builds of Mac Companion: control your Mac from an Android tablet over Tailscale.

Download from [Releases](https://github.com/phoenixSaket/macCompanion-releases/releases):

- **Mac** (macOS 13 or later): `MacCompanion-<version>-macOS.pkg` (installer), `.dmg` or `.zip`. The app is not notarized: the first time, right-click the app → **Open**.
- **Android**: `MacCompanion-<version>-android.apk`. Allow installs from the browser or file manager you open it with.

From 0.4.2 on, both apps check this page and offer to install newer versions themselves.
